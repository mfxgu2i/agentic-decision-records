# 9名以上の予約はオンラインで受けず、電話案内にする

## 背景

8名までは既存のテーブル配置のまま受け入れられる。9名以上はテーブルの組み替えや貸切の判断が必要で、
当日のほかの予約との兼ね合いを店長が決めている。フォームで受け付けても、その場では確定できない。

人数にかかわらずフォームで予約を受け付け、店舗から折り返して可否を伝える案もあった。
[予約データを永続化しない](0001-no-reservation-persistence.md) ため保留中の予約を管理する場所がなく、
折り返し漏れを防げないので選ばなかった。

## 決定

予約フォームとAPIが受け付ける人数は8名までとする。9名以上を入力した利用者には、電話番号を案内する。

## 影響

- この制限はコード上では人数の上限値としてしか現れない。上限を上げる変更は、店舗との合意なしに行わない
- 団体予約の需要はサイト上の予約データからは把握できない。把握するには店舗に電話での問い合わせ件数を確認する
