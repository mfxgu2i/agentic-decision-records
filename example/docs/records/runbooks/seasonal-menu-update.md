# 季節メニュー入れ替えの手順

`category: seasonal` の季節メニューを入れ替えるときに使う。CMSの編集権限とCDNの管理画面へのアクセス権が必要。

## 手順

1. CMSで旧季節メニューを非公開にする。削除はしない。過去メニューはアーカイブとして保持する運用
2. 新しいメニューを登録する。カテゴリには必ず `seasonal` を設定する。
   未設定の場合、`/menu?category=seasonal` の表示対象にならない
3. メニュー画像をアップロードする。既存の画像を上書きした場合は、CDNのキャッシュを必ずパージする。
   理由は [差し替えの反映が手動パージに頼っている問題](../issues/image-replace-needs-manual-purge.md) にある

## 確認

公開後、実機でトップページと `/menu?category=seasonal` の表示を確認する。差し替えた画像が新しいものに更新されていることも確かめる。
